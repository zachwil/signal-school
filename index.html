    MIDI CONTROLLER SETUP

    Connect. Learn. Play.

    Selected input: Your MIDI controller

    1. Connect your MIDI controller and click Connect MIDI. Allow MIDI access when prompted.
    2. Select its input from the MIDI input list. The app detects its reported name and manufacturer. With multiple devices, select the one you want to play.
    3. Click Enable sound. Notes from keys, note-mode pads, sequencers, or other note sources play the synth. CC-only control surfaces can adjust parameters while the on-screen keyboard plays notes.
    4. Click a parameter’s LEARN, then move a knob or fader. Map controls walks through up to eight assignments; cancel when you have mapped the controls you need.

    MIDI does not report a controller’s physical layout, knob labels, or control count. The app learns actual notes and CCs as they arrive; it does not guess factory mappings or reprogram your hardware. Mappings are saved separately per MIDI input and channel.

    Use absolute 0–127 CC mode for knobs and faders. Relative encoders, MIDI 2.0 UMP, and per-note MPE expression are not implemented. Channel pitch bend uses ±2 semitones; velocity, sustain (CC64), and modulation (CC1 → vibrato) are supported when the device sends them. Learned CC1 overrides vibrato. CC64 and CC120/123 are reserved.

    If no input appears, reconnect the device, enable its MIDI port, close other apps holding it, and click Refresh MIDI. Unsupported browsers can still use touch or computer keys. Octave buttons in the app affect only its on-screen and computer keyboards.

    Reference: Web MIDI API
